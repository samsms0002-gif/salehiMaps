# salehiMaps لويندوز

## التشغيل وإنشاء EXE

يتطلب Python 3.10 أو أحدث على ويندوز. شغّل `py -m pip install -r requirements.txt` ثم `py map_viewer.py`. لإنشاء تطبيق مستقل شغّل `build_windows.bat`؛ يضع PyInstaller الناتج في `dist\salehiMaps.exe`. اختر مجلد `files/datastore/maps` عند فتح العارض. لا يضم EXE بيانات الخرائط البالغ حجمها نحو 1.8 GB.

## ما ينفذه العارض

- استعراض صور الخرائط والصور/المعاينات الموجودة في مجلدات المستخدم، مع قائمة الطبقات.
- تركيب الطبقات وضبط شفافية كل طبقة، إضافةً إلى التحكم بالتشبع والتباين.
- التحريك والتكبير، عرض مركز الخريطة وإحداثياته، الانتقال إلى إحداثيات عشرية، وإظهار معاينة مهيأة من AQX.
- إنشاء معالم نقطية ومسارات قياس، وقياس المسافة الجيوديسية التقريبية.
- استيراد معالم GPX وKML وKMZ، وتصدير GPX أو KML.
- تصدير صورة العرض، حفظ جلسة العمل واستعادتها، وحفظ مجموعات خرائط مفضلة.
- الصور النقطية القياسية المدعومة من Pillow؛ ويمكن معايرة صور غير جغرافية بملف world file مثل JGW/PGW/TFW/WLD.

## فحص محتويات الحزمة

- `datastore/maps/*.AQX`: تعريفات XML لمصادر الخرائط، وتتضمن أسماء الطبقات وبعض قيم `preview-location`.
- `*.PREVIEW`: صور JPEG معاينة، وتمثل عينة صغيرة وليست مجموعة بلاطات كاملة.
- `*.DAT` و`*.IDX`: مخزن بلاطات مفهرس خاص بالتطبيق. لا يوجد في الحزمة وصف لصيغته الثنائية أو واجهة منشورة لفكه؛ لذلك لا يعرضها العارض ولا يحررها.
- `datastore/dem/N10E040.AQE`: بيانات ارتفاعات خاصة بالتطبيق وليست صورة أو DEM قياسي موثق.
- `files/maps` فارغ، ولا توجد ملفات خرائط جغرافية معايرة مستقلة في هذا المجلد.

إحداثيات المعاينة مأخوذة من مرجع AQX، لذا هي تقريبية لعينة العرض وليست ضماناً لتطابق بلاطات DAT. الخرائط المستقلة لا تقبل إحداثيات إلا إذا توفرت ملفات معايرة world file مناسبة.

## ميزات التطبيق الأصلي غير المتاحة هنا

مساعدة OfflineMaps تصف خرائط عند الطلب تحفظ البلاطات تلقائياً، حفظ مناطق بمستويات تكبير، فحص تغطية التخزين المحلي، مصادر خرائط المجتمع والخرائط الملفية، أنظمة إحداثيات وشبكات متعددة، GPS والبوصلة، بيانات الارتفاع، بحث الأماكن، أدوات متقدمة للمعالم (مناطق ومسارات وخصائص)، ومساحات عمل للتخزين. هذه النسخة لا تحقق التكافؤ الكامل: لا تفك صيغة البلاطات/الارتفاعات الخاصة، ولا تتصل بمزودي البلاطات، ولا توفر GPS أو بوصلة أو بحث أسماء الأماكن أو أنظمة الشبكات المسقطة. تحقيقها يتطلب بيانات/واجهات جغرافية موثقة ومصدر GPS ومصادر خرائط مرخصة.
